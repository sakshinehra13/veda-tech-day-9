# 🎓 Student Records Management System

Welcome to the **Student Records Management System**, built as part of the **Veda Technology Python Programming Track** (Level 1 - Task 9). 

This is an interactive web application built using **Python** and **Streamlit** that stores student names and marks in lists and performs various data operations.

---

## 🚀 Features

* **📋 View Student Directory:** Clean tabular view of all student records with automatically assigned grades (A, B, C, D, F).
* **➕ Add New Students:** Dynamically add new student names and marks using the interactive sidebar.
* **✏️ Update & Delete Records:** Easily modify student marks or remove records instantly.
* **📊 Performance Analytics:** Real-time metrics showing Highest Score, Lowest Score, Class Average, and a visual score distribution chart.
* **🔍 Quick Student Finder:** Instant lookup tool to search students by name and view their specific records.
* **🔄 Sort & Filter Options:** Reorder student records in ascending or descending order based on marks.
* **📥 Export Data:** Download the complete student dataset directly as a CSV file.

---

## 🛠️ Tech Stack

* **Language:** Python 3.x
* **Framework:** Streamlit
* **Data Manipulation:** Pandas
